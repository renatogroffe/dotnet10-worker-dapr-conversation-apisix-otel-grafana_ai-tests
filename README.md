# dotnet10-worker-dapr-conversation-apisix-otel-grafana_ai-tests
Exemplo de Console Application criado com o .NET 10 para testar IAs Generativas utilizando o building block de Conversation do projeto Dapr. Inclui exemplos em YAML com Microsoft Foundry, Grok e Google Agent Platform/Vertex (via APISIX como AI Gateway), monitoramento com OpenTelemetry + stack Grafana, além de um arquivo do Docker Compose para criação de ambiente de testes e um Dockerfile da aplicação.
